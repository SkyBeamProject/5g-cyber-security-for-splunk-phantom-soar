# Overview

A Splunk Phantom (SOAR) application that provides 5G cyber security automation. Specifically, it verifies the check digits of an eSIM eUICC Identifier (EID) according to GSMA SGP.29 "EID Definition and Assignment Process" v1.0 (31 July 2020).

Install the packaged `phverifyesimeuiccidentifier.tgz` into a Splunk Phantom instance to use the EID verification action in SOAR playbooks. See `README.md` for screenshots and installation steps.
